# Project Euler - Problem 12

## Problem

The sequence of triangular numbers is generated by adding the natural numbers: 1, 3, 6, 10, 15, ... The first ten terms are 1, 3, 6, 10, 15, 21, 28, 36, 45, 55. Find the value of the first triangular number to have over 500 divisors.

## Approach

Generated triangular numbers one at a time by accumulating a running sum (`ans += i` for each successive `i`). Before adding each new term, the divisor count of the current triangular number was checked using a helper function that counts divisors in `O(sqrt(n))` by checking factors up to the square root — each factor `i` found below the square root corresponds to a matching factor `x / i`, counted once if they're equal (a perfect square) or twice otherwise. The loop keeps generating the next triangular number as long as the current one has fewer than 500 divisors; it stops as soon as a triangular number reaches that threshold, which is the answer.

- **Time complexity:** `O(n * sqrt(T_n))`, where `n` is the index of the answer and `T_n` is its value — each triangular number requires a divisor count in `O(sqrt(T_n))`.
- **Space complexity:** `O(1)` — only a running sum and a divisor counter are used regardless of input size.
