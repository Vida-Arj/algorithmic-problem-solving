# Project Euler - Problem 2

## Problem

Each new term in the Fibonacci sequence is generated by adding the previous two terms. Starting with 1 and 2, find the sum of all even-valued terms in the sequence that do not exceed 4,000,000.

## Approach

Generated Fibonacci terms iteratively, starting from the first two values (1 and 2), and kept a running total of the even-valued terms. The loop stops as soon as a generated term reaches or exceeds 4,000,000, avoiding the need to store the full sequence.

- **Time complexity:** `O(log n)`, where `n` is the upper bound (4,000,000). The Fibonacci sequence grows exponentially, so the number of terms generated before exceeding `n` is proportional to `log(n)`.
- **Space complexity:** `O(1)` — only the last two terms are kept at any time, no array or list is used.
