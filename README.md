## Overview

I'm a Computer Science graduate, and I solved these problems — mostly from Project Euler and Timus — to reinforce what I learned during my ACM training. This repository is organized by source, with each problem kept in its own folder along with a short write-up of my approach.

## How Each Solution is Organized

Every problem lives in its own folder and includes:

- **`solution.cpp`** — the source code for the problem.
- **`README.md`** — a short write-up covering:
  - A brief summary of the problem (in my own words)
  - My approach and reasoning
  - Any notable edge cases or complexity considerations
